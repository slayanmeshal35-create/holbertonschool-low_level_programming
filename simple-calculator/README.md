
# Simple Calculator

This project is a simple calculator written in C.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Quit the program using option 0.

## Compilation
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Usage
./calculator
## Number Type

The calculator uses double-precision floating-point
numbers for all arithmetic operations.

Division supports decimal results.
Division by zero displays an error message.
